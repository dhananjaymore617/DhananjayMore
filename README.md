# 👨‍💻 About Me

I am Dhananjay More, a Data Analyst passionate about transforming raw data into meaningful insights that support smarter business decisions.

I specialize in:

* Turning raw and complex datasets into clear, actionable insights
* Writing SQL queries to extract, transform, and analyse data
* Building interactive dashboards using Power BI and Excel
* Identifying trends, patterns, KPIs, and business insights
* Working across the end-to-end analytics workflow, from data preparation to visualization

What drives me most is problem-solving — understanding business challenges and using data to answer the **“why”** behind them.

I enjoy:

* 📊 Building dashboards that simplify decision-making
* 🔍 Finding meaningful patterns and trends in data
* 🗄️ Working with SQL, data modelling, and cloud-based analytics
* 🚀 Continuously learning and strengthening my data analytics skills

I believe data is not just numbers — it's a language, and I enjoy translating it into insights that support better decisions.
